## About This Repository

This repository contains Python programs developed for the Python
Activity-Based Learning assignment. The programs demonstrate concepts
such as variables, data types, operators, conditional statements, loops,
strings, lists, and basic problem-solving.

## How to Run the Programs

1.  Install Python 3 on your computer.

2.  Download or clone this repository.

3.  Open a terminal or command prompt in the project folder.

4.  Run a program using:

    ``` bash
    python filename.py
    ```

    Replace `filename.py` with the name of the Python file you want to
    execute.
